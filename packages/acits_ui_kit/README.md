# acits_ui_kit

Design system for ACITS: Material 3 tokens (`AppTheme`/`AppColors`), breakpoints,
`AdaptiveScaffold`, and token-driven base components.

## Assets

The package owns only its icon font (`assets/font/icomoon.ttf`, exposed via
`IconRes`). It does NOT own the app's images/SVGs — those stay app-owned and are
generated by the root `flutter_gen` pipeline into `lib/gen/`. `IconRes` icons
reference the font with `fontPackage: 'acits_ui_kit'`, so they resolve from the
package regardless of the consuming app.
